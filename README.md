# 🧮 Calculadora Web Simples

Este é um projeto completo de desenvolvimento web, criado com o objetivo de consolidar os fundamentos em HTML, CSS e JavaScript puro.

O valor deste projeto reside na prática da execução completa: desde a codificação inicial até o deploy final no GitHub Pages.

## 🚀 Tecnologias Utilizadas

| Tecnologia | Função |
| :--- | :--- |
| **HTML5** | Estrutura semântica e conteúdo. |
| **CSS3** | Estilização, layout flexível e responsividade. |
| **JavaScript** | Lógica completa das operações matemáticas e manipulação de eventos do DOM. |

## 💡 Aprendizados Chave

* Configuração e uso de **Git** e **GitHub** (commit, push, e configuração de repositório remoto).
* Tratamento de *strings* de entrada para a lógica matemática em JavaScript.
* Uso de *event listeners* para capturar a interação do usuário na interface.
